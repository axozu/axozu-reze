# axozu blink

Десктопное приложение (Electron) с бесконечной анимацией персонажа: моргание
(open → half → closed → half → open), проявляющаяся надпись **axozu**, колыхание
волос по маске и лёгкое «дыхание» кадра, плёночный цветокор (по умолчанию ч/б) с зерном и виньеткой.
Всё считается в реальном времени во фрагментном шейдере WebGL2 — без видео и GIF.

## Запуск

```bash
npm install
npm start
```

Нужен Node.js 18+. При первом `npm start` Electron может докачать свой бинарник.

## Сборка

```bash
npm run build        # сборка под текущую ОС: Windows → portable .exe, macOS → .dmg
npm run build:win    # явно portable .exe
npm run build:mac    # явно .dmg (только на macOS)
```

Результат — в `dist/`. Portable `.exe` запускается двойным кликом, Node не нужен.
`.dmg` собирается только на Mac (ограничение electron-builder/Apple-инструментов).
Сборки не подписаны: на Mac при первом запуске — правый клик → «Открыть».

## Управление

| Действие | Как |
|---|---|
| Перетащить окно | зажать ЛКМ в любом месте |
| Изменить размер | тянуть за край окна (пропорции 2252:1544 сохраняются) |
| Свернуть / закрыть | кнопки в правом верхнем углу (появляются при наведении) |
| Выйти | `Esc` или двойной клик |
| Поверх всех окон | ПКМ → «Поверх всех окон» |
| Цвет | ПКМ → «Цвет» (ч/б плёнка / цветная плёнка / оригинал) или клавиша `G`; выбор запоминается |
| Отладка фазы | `D` — показать/скрыть фазу цикла, прогресс век, прозрачность надписи, fps |

## Структура

```
main.js       окно: frameless, пропорции, перетаскивание, контекстное меню
preload.js    IPC-мост: кнопки окна, перетаскивание, выбор цветокора
index.html    canvas, надпись, кнопки
renderer.js   константы + цикл requestAnimationFrame + шейдер
easing.js     функции плавности
assets/       кадры, маски и поля потока для глаз (flow_*.png)
tools/        make_eye_flow.py — генерация полей потока
build/        иконка приложения
```

`_source/` и `TZ.md` не входят ни в репозиторий, ни в сборку. `assets/eye_mask.png` нужен
только скрипту `tools/make_eye_flow.py`, приложение его не загружает.

### Поля потока для глаз

`assets/flow_open_half.png`, `flow_half_open.png`, `flow_half_closed.png`,
`flow_closed_half.png` сгенерированы скриптом `tools/make_eye_flow.py` (OpenCV,
DIS optical flow) и уже лежат в репозитории. Перегенерировать нужно, только если
поменялись `open/half/closed.jpg`:

```bash
pip install opencv-python numpy
python tools/make_eye_flow.py
```

R = смещение по X, G = по Y в пикселях кадра 2252×1544, 128 = ноль.

## Как устроен рендер

Один цикл `requestAnimationFrame`. Время — `performance.now()`, фаза цикла
`(t % CYCLE) / 1000`. Шейдер за один проход:

1. **Глаза** — не кроссфейд, а морфинг по оптическому потоку. Прогресс закрытия
   `k` (0…1, через easing) делится на сегменты `open → half` (`0…HALF_KEY`) и
   `half → closed` (`HALF_KEY…1`). Для каждой пары кадров заранее посчитаны поля
   смещения пикселей в обе стороны (`assets/flow_*.png`). Внутри сегмента с
   позицией `t` кадр A берётся со сдвигом `t·F(A→B)`, кадр B — со сдвигом
   `(1−t)·F(B→A)`, и они смешиваются только в середине сегмента
   (`EYE_MORPH_BLEND`). Поэтому веко едет вниз и вверх, как на видео, а не
   «перещёлкивается». Вне глаз поле нулевое, а кадры совпадают попиксельно —
   швов нет.
2. **Волосы** — в каждой точке берётся вес из `hair_mask.png`, смещение =
   вес × амплитуда × сумма трёх синусоид, фаза которых зависит от времени, Y
   (и немного X), поэтому пряди качаются волной. Лицо и глаза в маске чёрные — не
   двигаются. Мягкий край маски даёт непрерывное смещение, пряди не рвутся.
3. **Дыхание** — масштаб от центра и небольшой сдвиг. Сдвиг всегда меньше
   запаса, который даёт масштаб, а картинка вписана как `object-fit: cover` —
   пустых полей не бывает.
4. **Цветокор** — насыщенность, гамма, S-кривая контраста, сплит-тон теней и
   светов, матовый чёрный, виньетка и зерно (меняется 24 раза в секунду, как
   плёнка).

Надпись — HTML-элемент поверх canvas (`text-shadow` для свечения).

Шва на стыке цикла нет: в конце и в начале цикла глаза открыты, надпись видна
полностью, буст волос равен нулю. Волосы и дыхание идут от непрерывного времени, а
их периоды по умолчанию — доли цикла (`CYCLE_S`, `/2`, `/3`), так что всё строго
периодично.

### Отступления от исходного ТЗ

Тайминги ускорены: моргание 13 с ощущалось как замедленная съёмка. Сейчас цикл
7.9 с — 4.2 с глаза открыты, закрытие 1.0 с, 1.4 с закрыты, открытие 1.3 с.
Надпись по-прежнему исчезает до начала закрытия и проявляется ровно к полному
открытию. Добавлен цветокор, по умолчанию — ч/б: он подчёркивает карандашную
штриховку рисунка.

## Константы (`renderer.js`, вверху файла)

Тайминги в секундах. Достаточно поменять константу — остальной код не трогать.

### Глаза

| Константа | По умолчанию | Что делает |
|---|---|---|
| `OPEN_HOLD` | 4.2 | сколько глаза открыты от начала цикла |
| `CLOSE_DUR` | 1.0 | длительность закрытия |
| `CLOSED_HOLD` | 1.4 | сколько глаза закрыты |
| `OPEN_DUR` | 1.3 | длительность открытия |
| `CYCLE` / `CYCLE_S` | 7900 мс / 7.9 с | длина цикла, считается как сумма четырёх выше |
| `HALF_KEY` | 0.55 | прогресс закрытия, на котором показан кадр `half.jpg` |
| `EYE_EASING` | `easeInOutSine` | плавность век (имя функции из `easing.js`) |
| `EYE_MORPH` | true | морфинг по потоку; `false` — простой кроссфейд кадров |
| `EYE_MORPH_BLEND` | 0.3, 0.7 | окно внутри сегмента, где пиксели A сменяются пикселями B (`[0, 1]` — плавнее, но больше двойных контуров) |
| `FLOW_RECT` | 470, 220, 1290×540 | область кадра, которую покрывают поля потока |
| `BLINK_JITTER_ENABLED` | false | случайный разброс паузы между морганиями |
| `BLINK_JITTER` | 0.5 | величина разброса, ± с (меняет удержание открытых глаз) |

### Надпись

| Константа | По умолчанию | Что делает |
|---|---|---|
| `TEXT_FADE_OUT_DUR` | 1.1 | длительность исчезания |
| `TEXT_FADE_IN_DUR` | 1.5 | длительность проявления |
| `TEXT_FADE_OUT_START` / `TEXT_FADE_OUT_END` | 3.1 / 4.2 | исчезание; конец привязан к началу закрытия глаз |
| `TEXT_FADE_IN_START` / `TEXT_FADE_IN_END` | 6.4 / 7.9 | проявление; конец привязан к полному открытию глаз |
| `TEXT_EASING` | `easeInOutSine` | плавность прозрачности |
| `TEXT` | `axozu` | текст |
| `TEXT_FONT`, `TEXT_WEIGHT` | Segoe UI Light / Helvetica Neue, 200 | шрифт |
| `TEXT_SIZE` | 0.052 | размер шрифта, доля ширины окна |
| `TEXT_LETTER_SPACING` | 0.55em | межбуквенный интервал |
| цвет и свечение | см. `GRADES` | задаются в каждом пресете цветокора (`textColor`, `textGlow`) |
| `TEXT_Y` | 0.80 | вертикальная позиция центра, доля высоты окна |
| `TEXT_SHIFT` | 6 | сдвиг по Y при появлении/исчезании, px (окно 1126×772) |

### Волосы

| Константа | По умолчанию | Что делает |
|---|---|---|
| `HAIR_AMP` (`HAIR_AMPLITUDE`) | x 3.5, y 1.5 | макс. смещение в px кадра 1126×772 |
| `HAIR_PERIODS` | 7.9, 3.95, 2.63 | периоды трёх синусоид, с |
| `HAIR_WEIGHTS` | 1, 0.55, 0.25 | вклад каждой синусоиды |
| `HAIR_WAVE_Y` | 5.0 | зависимость фазы от Y — «волна» вдоль прядей |
| `HAIR_BLINK_BOOST` | 0.20 | усиление амплитуды во время моргания (+20%) |
| `HAIR_BOOST_RAMP` | 0.8 | время плавного нарастания и спада усиления, с |

### Дыхание

| Константа | По умолчанию | Что делает |
|---|---|---|
| `BREATH_PERIOD` | 3.95 | период, с (половина цикла) |
| `BREATH_SCALE` | 0.006 | масштаб 1.0 → 1.006 |
| `BREATH_SHIFT` | x 0.6, y −1.5 | сдвиг на пике, px кадра 1126×772 (держать меньше запаса от масштаба: ~3.4 px по X, ~2.3 px по Y) |

### Цветокор

| Константа | По умолчанию | Что делает |
|---|---|---|
| `GRADE_DEFAULT` | `bw` | пресет при первом запуске: `bw`, `film` или `none` |
| `GRAIN_FPS` | 24 | сколько раз в секунду меняется зерно |
| `GRADES` | — | пресеты. Поля: `sat` (0 = ч/б), `gamma` (>1 плотнее полутона), `contrast` (S-кривая), `fade` (подъём чёрного), `shadow` / `high` (тонирование RGB), `vignette`, `grain`, `textColor`, `textGlow` |
